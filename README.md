# 折页旅行 - Folded Atlas

> 一款专为多人旅行设计的画册式行程规划工具，手机和电脑都能用。
> 视觉风格：自然景观配色（苔藓森林 / 暖沙 / 天青湖水 / 夕照暖光）

![折页旅行](https://img.shields.io/badge/version-2.0-9cf)

---

## 功能一览

### 1. 主标题
- 自定义旅行标题（如"北京之旅 2026"）
- 右上角分享码，方便多人加入同一行程

### 2. 旅行设置
- 填写目的城市名称
- 上传城市地图图片（自动压缩保存）
- 设置出发日期和返程日期，自动生成每日行程卡片
- 添加/删除参与人员

### 3. 画册式每日计划
- 每天一张卡片，横向滑动切换
- 纵向展示 24 小时时间轴（00:00 – 23:00）
- 每个小时可写多个活动卡片
- 顶部固定天数标签，滑动时同步高亮

### 4. 消费计算
- **六大分类**：交通、住宿、餐饮、门票、购物、其他
- **按天筛选**：可只看某一天的花费
- **谁付了钱**：每笔消费可指定付款人
- **每人分摊**：每人填自己花了多少，支持"平分"按钮一键均摊
- **每天小计**：切换"所有天"时显示每天合计
- **每人小计**：显示每人付了多少钱、花了多少钱
- **总计**：所有人花费合计
- **结算建议**：自动计算最小转账（谁欠谁、谁该退谁）

### 5. 美图上传
- 支持拍照（手机）或相册上传
- 自动压缩图片（JPEG 82% 质量）
- 瀑布流网格布局（手机 2 列，PC 3–4 列）
- 点击图片全屏放大（Lightbox）
- Lightbox 支持左右滑动 + 键盘方向键导航
- 所有成员共享同一相册

## 快速开始

### 在本机运行

```bash
cd travel-plan

# 安装依赖（已安装好，可跳过）
npm install

# 启动前后端服务
npm run dev
```

启动后打开浏览器访问 `http://localhost:5173`

## 设计风格

**配色体系**：自然景观灵感
- 苔藓森林绿 `#3d6b47` — 主强调色（按钮、选中态）
- 暖沙岩 `#c4a882` — 辅助色（边框、占位）
- 天青湖水 `#6a9fbc` — 点缀（渐变、装饰）
- 夕照橙 `#c47a3a` — 野莓红 `#a85c5c` — 警告色

**UI 特点**：
- 多层柔和自然渐变背景 + 纸张微纹理
- 所有边框柔和（不再生硬）
- 卡片化布局，圆角 + 轻阴影
- Tab 栏毛玻璃效果
- 按钮 hover 动效（下沉 + 阴影）
- 消费统计用彩色数据卡替代原始表格
- 拍立得风格照片卡：白色底边 + 日期水印 + 上传人署名

### 手机访问（同一 Wi-Fi）

服务启动后，终端会显示局域网地址，例如：

```
API http://127.0.0.1:8787
LAN  http://192.168.1.100:5173
```

手机连接同一 Wi-Fi 后，浏览器打开 `http://192.168.1.100:5173` 即可使用。

### 多人共用同一行程

1. **创建者**：打开页面 → 输入主标题 → 点击"开一本新折页"
2. **加入者**：打开页面 → 输入分享码（6位字母数字）→ 点击"加入"

所有数据（行程 / 消费 / 图片）自动同步，无需登录。

## 技术说明

| 项目 | 说明 |
|---|---|
| 前端 | React 19 + Vite + TypeScript |
| 后端 | Express 5（Node.js） |
| 数据 | 本地 JSON 文件存储（`data/` 目录） |
| 图片 | 本地磁盘存储（`uploads/` 目录） |
| 无需账号 | 分享码即通行证，同一 Wi-Fi 下天然互通 |

**数据位置：**
- `data/*.json` — 所有行程数据（可备份）
- `uploads/*/` — 上传的地图和照片

## 使用技巧

### 消费记账顺序
1. 先在「城市」里添加所有同行人
2. 在「花费」里点击「记一笔」
3. 选择谁付的这笔钱（谁付）
4. 每个人填自己花的那份（可以不填，默认 0）
5. 点击「平分」可一键均摊

### 结算建议原理
系统追踪两件事：
- **谁付了钱**：每笔消费的"谁付"字段累加
- **谁花了钱**：每人金额累加

然后用 Greedy 算法算出最少转账次数——比如甲欠乙 ¥300、乙欠丙 ¥200，系统会合并为"甲 → 乙 ¥300，乙 → 丙 ¥200"，而不是让甲直接转丙。

### 相册协作
- 上传的照片会出现在所有人的相册里（刷新即可见）
- 同一分享码的用户都可以上传
- 每人只能删除自己上传的照片
- 照片标题可填写备注

## 生产部署

```bash

npm run build
```
